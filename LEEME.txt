================================================================================
SEÑALES MÁS USADAS
================================================================================

  1  SIGHUP   - terminal cerrado
  2  SIGINT   - CTRL+C
  3  SIGQUIT  - CTRL+\
  9  SIGKILL  - matar (no se puede ignorar)
 10  SIGUSR1  - señal usuario 1
 12  SIGUSR2  - señal usuario 2
 15  SIGTERM  - terminar (se puede ignorar)
 17  SIGCHLD  - hijo cambió estado
 18  SIGCONT  - reanudar proceso suspendido
 19  SIGSTOP  - suspender (no se puede ignorar)
 20  SIGTSTP  - CTRL+Z (se puede ignorar)
 21  SIGTTIN  - bg intentó leer del terminal
 22  SIGTTOU  - bg intentó escribir en terminal

// kill(pid, sig) - mandar señal a un proceso
// pid < 0: mandar al grupo |pid|
kill(pid_fork, SIGKILL);
kill(-pgid, SIGCONT);  // equivalente a killpg

// killpg(pgid, sig) - mandar señal a todo un grupo
killpg(pgid, SIGKILL);
killpg(pgid, SIGCONT);
killpg(pgid, SIGSTOP);
killpg(pgid, 0);        // comprobar si el grupo existe (sin matar)

// mask_signal(signal, block) - bloquear/desbloquear señal
// (función propia del shell, implementada con sigprocmask)
mask_signal(SIGCHLD, SIG_BLOCK);    // bloquear
mask_signal(SIGCHLD, SIG_UNBLOCK);  // desbloquear


================================================================================
FLAGS DE open() MÁS USADOS
================================================================================

  O_RDONLY              → solo lectura (para redirección <)
  O_WRONLY | O_CREAT | O_TRUNC   → escritura, crear si no existe, vaciar (>)
  O_WRONLY | O_CREAT | O_APPEND  → escritura al final (>>)
  Tercer argumento: 0644 (permisos: dueño rw, grupo r, otros r)
